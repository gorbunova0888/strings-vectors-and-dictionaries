# Лабораторная работа 5: Строки, векторы и словари

## Автор
Горбунова Настя (Вариант 5)

## Цель работы
Научиться обрабатывать текст с помощью строк, хранить последовательности в векторе и находить данные по ключу в словаре. Выполнить отдельное упражнение с каждой конструкцией и объединить их в обработке списка записей.

## Что делает программа
Программа состоит из четырех частей, которые выполняются последовательно:
1. **Часть А:** Считывает строку и подсчитывает количество пробелов в ней.
2. **Часть В:** Считывает вектор целых чисел и удаляет из него дубликаты, сохраняя порядок первых вхождений.
3. **Часть С:** Считывает словарь (ключ-значение) и находит ключ с максимальным значением.
4. **Часть D:** Считывает список записей (предмет и тема) и группирует темы по предметам, сохраняя порядок их появления.

## Входные данные
Программа запрашивает данные с клавиатуры по очереди:
- **Строка** (текст с пробелами).
- **Количество элементов** вектора и сами числа.
- **Количество пар** словаря и сами пары (ключ и число).
- **Количество записей** и сами записи (сначала предмет, затем тема).

## Выходные данные
Для каждой части выводится результат с пометкой `Answer:`. 
Для списка записей выводится сгруппированный список в формате `Предмет: тема1, тема2`.
